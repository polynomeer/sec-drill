# T04·T06 Lab 수명과 실행 격리

상태: **Lab 수명·local-trusted 개발 경로 구현·로컬 검증 완료, strong isolation(`lab-strong`) 미검증·blocker**(2026-10-05). 실행 지침: [프롬프트 07](prompts/07-lab-isolation.md). 결정: [ADR 0007](../adr/0007-lab-lifecycle-local-trusted-runtime-and-gateway.md).
관련 요구: FR-03, NFR-02. 원문: [30](../../SecDrill-docs/docs/30-implementation-plan.md) T04·T06, [17](../../SecDrill-docs/docs/17-sandbox-isolation.md) "출시 검증".

**외부 공개 금지.** 이 단계의 runtime은 `local-trusted`(hardened Docker)이며 강한 격리가 아니다. 학습자 공격 Lab과 외부 파일럿은 strong runtime 검증 뒤에만 연다.

## 실제 검증(local-trusted 프로파일만)

`LocalTrustedIsolationTest`가 실제 Docker에서 아래를 확인한다. **이 결과는 strong isolation의 증거가 아니다.**

| 17 출시 검증 항목 | local-trusted 결과 |
|---|---|
| 외부 egress IPv4·IPv6 | 차단(`--internal`), 기본 bridge에서는 같은 probe 성공(probe 유효성) |
| DNS 외부 해석 | 차단 |
| metadata(169.254.169.254) | 차단 |
| Control Plane(host·host gateway IP 경유) | 차단 |
| 다른 Lab(이름·IP) | 차단, 자기 app은 응답(양성 대조) |
| host mount·Docker socket·device | 없음 |
| PID 제한(fork bomb) | PID 64에서 fork 거절 |
| memory flood | 64 MiB에서 해당 프로세스 OOM kill, Lab 유지 |
| output flood | 1 MiB에서 truncate |
| namespace 생성 | seccomp로 `unshare -U/-n/-m` 거절. **seccomp 미지정 시 이 호스트에서 user namespace 생성이 성공**해 adapter가 profile을 강제하고 mode 2를 확인한다 |
| Control 장애 중 hard TTL | label 기반 local 회수 |
| 취소 뒤 생성된 자원 | late callback → 회수, receipt에 container·network |
| guest escape 의심 시 runner quarantine | 미구현 |

## Blocker와 미검증

- **strong runtime 없음(D-10)**: KVM이 있는 Linux runner host가 필요하다. 위 표 전체를 microVM runtime에 대해 다시 통과해야 한다.
- rootless Docker daemon(17의 local-trusted 행): 이 호스트는 일반 daemon. 미검증
- Linux host의 Docker 동작·CI 실행: push 전
- Gateway→Lab 실제 network 경로: Docker Desktop은 host에서 internal network로 라우팅하지 않는다. Gateway 테스트는 로컬 upstream
- 터미널 websocket(17), 출력 속도 제한: 미구현
- 이미지 registry 서명 검증(D-16): digest 고정만
- mTLS workload identity·노드 등록(D-17)
- connect nonce·gateway session의 다중 인스턴스 공유, Gateway 운영 배포

## 남은 것

- strong runtime adapter와 같은 격리 테스트(D-10 결정 후)
- runner quarantine, 터미널 transport, 이미지 서명 검증
- Session 생성·조회 API(`POST /sessions`, `GET /sessions/{id}`): 아직 없다. 테스트는 fixture로 ACTIVE Session을 만든다. Lab 상태는 requestLab·stop 응답에만 있다
