# T13 MVP 콘텐츠와 Transfer

상태: **기본 3개 + 전이 3개 사건 저작·local-trusted 채점 검증 완료; 출판·독립 검수 미완**(2026-10-05). 실행 지침: [프롬프트 13](prompts/13-content-transfer.md).

**출판 불가·독립 검수 미완·데모.** strong runtime verifier가 없어(D-10) 이 콘텐츠는 출판 게이트를 통과하지 못한다(INCOMPLETE). 독립 검수자가 플레이하지 않았으므로 독립 검수 완료로 표시하지 않는다. 채점은 격리 미검증 local-trusted에서 수행되어 모든 결과가 데모다.

## 기본 사건(3)

| 계열 | lab | 발견 목표 | 수정 증명(패치 경로) |
|---|---|---|---|
| Tenant leak | content/labs/tenant-orders | 다른 테넌트 합성 주문 접근 | app/orders.py, app/authz.py |
| Webhook replay | content/labs/webhook-receiver | 캡처한 서명 배송 재전송으로 중복 지급 | app/verify.py, app/dedup.py |
| Over-broad API token | content/labs/api-gateway | scope 밖 합성 자원 접근·폐기 토큰 사용 | app/tokens.py, app/scopes.py |

각 사건에 정상 baseline(취약 app), 참조 수정판, 핵심 mutant, 숨은 보안(deny)·정상 회귀(allow) 검사, 힌트(H1~H4), 회고 질문을 두었다. 비공개 자료는 `private/`이며 `.dockerignore`로 Lab 이미지에서 제외한다.

## 검증 결과

- `ContentSuiteTest`(실제 채점, local-trusted Docker): webhook·api-gateway 각각 참조 패치 VERIFIED, 핵심 mutant 전부 NOT_VERIFIED이고 기대한 gate(security·regression·compile)에서 실패. tenant-leak은 `PatchGradingTest`가 동일하게 검증.
  - webhook mutant: no-change·dedup-only·freshness-only·tamper-framework(security), reject-everything·dedup-by-amount(regression), compile-error(compile)
  - api mutant: no-change·reports-implies-all·trust-client-scope·fix-scope-not-revoke(security), reject-everything(regression), compile-error(compile)
- `DetectionSeedSuiteTest`(순수 엔진): tenant-leak 탐지 drill의 경계 seed 20 + 무작위 seed 100에서 행동 기반 규칙은 holdout PASS(생성기 solvable), 이름 암기 규칙은 holdout FAIL(전이 저항). training·holdout 이름 비중복.
- 채점 드라이버(`grading-driver.py`)를 일반화: POST 본문, 서버가 돌려준 값으로 요청 구성(`from`, 캡처 재전송), `fieldEquals`·`bodyContains`·`bodyExcludes`·`setup`. tenant-orders 기존 채점과 호환.

## 전이 사건(3)

| 전이 | lab | 같은 개념, 다른 계열 |

## 미완(남은 것)

- **출판**: strong runtime verifier 없음(D-10)으로 출판 게이트 INCOMPLETE. 출판용 on-disk 번들(manifest/oracle/서명) 미작성.
- **독립 검수자 플레이** 미완 → 독립 검수 완료로 표시하지 않음.
- 전이·신규 기본 사건의 FLAG 발견 목표 독립 관측(ObjectiveObserver predicate)은 tenant-orders만 구현. 비핵심 mutant kill-ratio 90% 목표·파일럿 결과 미완.
