# T07 첫 사건 CTF 수직 기능

상태: **API·Gateway·runner 경로 구현과 로컬 검증 완료, 결과는 데모(격리 미검증)**(2026-10-05). 실행 지침: [프롬프트 08](prompts/08-first-ctf.md). 결정: [ADR 0008](../adr/0008-ctf-flags-objective-observation-and-demo-results.md).
관련 요구: FR-04, FR-07. 원문: [30](../../SecDrill-docs/docs/30-implementation-plan.md) T07 "CTF 목표 verifier·flag", 완료 증거 "session binding·oracle 비노출".

**외부 공개 금지.** Lab은 `local-trusted`(hardened Docker)에서만 돈다. 모든 평가는 `demo: true`, Lab은 `isolationVerified: false`로 응답하고 UI가 데모 배너를 띄운다. strong runtime이 없는 동안(D-10) 공식 결과는 없다.

## 흐름

로그인 → `GET /v1/scenarios`(사건 선택) → `POST /v1/sessions`(PUBLISHED 버전 고정, CREATED) → `POST /labs` → runner가 합성 tenant-orders 이미지를 생성(READY, Session ACTIVE) → `POST /labs/{id}/connect` → Lab Gateway(별도 origin)로 합성 서비스에 접근 → 다른 tenant 주문에서 Session 플래그 획득 → `POST /submissions`(FLAG) → 메모리 HMAC 검사와 서명 receipt → runner가 서버 측 접근 기록 관측 → Evaluation·`OBJECTIVE_CONFIRMED` Evidence → `GET /v1/submissions/{id}`(결과) → `POST /finish`(SUBMITTED, Lab 종료) → cleanup receipt.

합성 사건: [content/labs/tenant-orders](../../content/labs/tenant-orders/app/app.py). Northwind 사용자 `alice`가 `GET /api/orders/<id>`의 tenant 검사 누락으로 Contoso 주문을 읽는다. 데이터와 자격증명은 모두 합성이다.

추가: 관측 없는 정답 SYSTEM_ERROR/INCONCLUSIVE(FAIL 아님), 변조 receipt는 재시도 후 SYSTEM_ERROR·감사, 오답 분당 10건 429·`Retry-After`, FAIL 결과 Session은 finish 409 `objective_confirmed`.

## 미검증과 위험

- strong runtime(D-10)에서의 같은 흐름과 guest 밖 관측. 지금 관측 기록은 Lab 안에 있어 Lab 코드 실행을 얻으면 위조할 수 있다
- 브라우저로 전체 UI 흐름: local profile에서는 runtime verifier가 없어 콘텐츠를 출판할 수 없다(ADR 0006 게이트). 게이트를 우회하는 데모 출판 경로는 만들지 않았다. 로컬 runner·Gateway 실행 진입점도 아직 없다(테스트가 직접 띄움)
- local-trusted relay는 egress가 있는 bridge에 붙는다(ADR 0008)
- 플래그는 Lab 컨테이너 환경과 runner host `docker inspect`에 보인다. content 검수 항목
- 개발용 flag key·catalog cursor 키는 프로세스별(재시작 시 무효)
- 최종 리포트 job(EVALUATING→COMPLETED, T12)·힌트·점수 차감은 미구현
