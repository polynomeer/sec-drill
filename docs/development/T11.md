# T11 CTF·Wargame·Purple 작업 공간

상태: **Web 작업 공간 구현과 브라우저 E2E(계약 타입 가짜 API) 통과, 실제 Lab까지의 브라우저 전체 흐름은 미검증**(2026-10-05). 실행 지침: [프롬프트 11](prompts/11-workspace.md). 결정: [ADR 0011](../adr/0011-learner-workspace-web.md), D-06.

실행: `cd web && npm ci && npm run build`로 만든 결과를 Control Plane이 `/app/`에서 제공한다. 개발 중에는 `npm run dev`(API는 127.0.0.1:8080으로 proxy). E2E는 `PLAYWRIGHT_BROWSERS_PATH=.playwright npx playwright install chromium` 뒤 `npm run e2e`.
