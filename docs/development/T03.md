# T03 콘텐츠 저작·검증·출판 기반

상태: **기반 구현·로컬 검증 완료. 실제 runtime 검증이 없어 기본 설정에서는 어떤 번들도 출판되지 않는다**(2026-10-05). 실행 지침: [프롬프트 06](prompts/06-content-publishing.md). 결정: [ADR 0006](../adr/0006-content-bundles-signing-and-publish-gate.md).
관련 요구: FR-02(버전 고정), FR-09. 원문: [30](../../SecDrill-docs/docs/30-implementation-plan.md) T03 "Scenario bundle·검증·서명·publish", 완료 증거 "reference/mutant와 승인 분리".

## 결과

| 프롬프트 항목 | 상태 | 증거 |
|---|---|---|
| 공개 manifest와 private oracle 분리 | 완료 | 두 JSON Schema, 분리·누출 검사, private store, 학습자 API는 manifest 필드만 |
| 버전과 canonical digest | 완료 | content·oracle·bundle digest(RFC 8785), 버전 불변 trigger |
| 이미지·콘텐츠 서명 검증 | 콘텐츠 완료, 이미지 미검증 | Ed25519 번들 서명이 imageDigest를 포함. registry 이미지 서명은 T06 |
| 참조 해답·mutant·seed 검증 인터페이스 | 인터페이스만 | `RuntimeVerifier`, 기본은 NOT_RUN. 실제 verifier는 T06·T08 |
| 검증 보고서 | 완료 | `content_validation_reports`, PASS·FAIL·INCOMPLETE와 check 목록 |
| 작성자·승인자 분리 | 완료 | API 403, DB CHECK·FK, 역할 분리 |
| 출판·차단·버전 고정 | 완료 | 독립 승인 trigger, 차단 후 숨김·재개 불가, 이전 출판 버전 조회 |
| 미검증 번들의 게이트 차단 | 완료 | 기본 설정에서 INCOMPLETE·DRAFT, prod는 test verifier 거부 |
| 예제 placeholder·publishable 유지 | 완료 | 예제는 FAIL로 출판 불가. 추가한 필드는 difficulty·estimatedMinutes(F-14)와 detection 비율 bps 표기(F-15) |

| 운영 화면 | CLI·내부 API로 대체 | `content` CLI, `/ops/v1/...` |

## 남은 것

- 콘텐츠 승인자 디렉터리와 2인 승인 인력(D-11), Web build 산출물의 oracle 검사(T11)
