# T10 탐지 DSL과 사고 대응 모델

상태: **탐지 DSL·지표·holdout 채점과 IR reducer·액션 API 구현과 로컬 검증 완료**(2026-10-05). 실행 지침: [프롬프트 10](prompts/10-detection-ir.md). 결정: [ADR 0010](../adr/0010-detection-dsl-and-incident-model.md).
관련 요구: FR-05. 원문: [30](../../SecDrill-docs/docs/30-implementation-plan.md) T10 "detection DSL·holdout·IR reducer", 완료 증거 "ground truth·N/A·action tradeoff fixtures".

탐지와 대응은 모두 합성 데이터 위의 모델이다. 결과는 `SIMULATED`로 기록하며 실제 Lab 조치로 표시하지 않는다.

| 프롬프트 항목 | 상태 | 증거 |
