# T09 Evidence Ledger와 Artifact 기반

상태: **기반 구현·로컬 검증 완료, 개인정보 삭제 실행은 미구현**(2026-10-05). 실행 지침: [프롬프트 05](prompts/05-evidence-artifacts.md). 결정: [ADR 0003](../adr/0003-canonical-digest-and-evidence-hash.md), [ADR 0005](../adr/0005-evidence-trust-artifacts-and-runtime-role.md).
관련 요구: FR-07, NFR-03. 원문: [30](../../SecDrill-docs/docs/30-implementation-plan.md) T09 "Ledger·hash·artifact policy", 완료 증거 "concurrent append·gap·delete tombstone".

## 결과

| 프롬프트 항목 | 상태 | 증거 |
|---|---|---|
| Session별 seq와 head 갱신 | 완료 | 동시 append 24건 연속 seq |
| canonical payload digest와 hash chain | 완료 | ADR 0003 벡터, `LedgerVerifier`가 수정·gap·truncate 탐지 |
| source·trustLevel 구분 | 완료 | 앱·DB 이중 강제, USER는 USER_REPORTED만 |
| 일반 앱 권한의 append-only | 완료(권한 정의) | `control_app` 역할 테스트. 배포에서 런타임이 이 역할로 접속하는 것은 미검증(D-14) |
| private Artifact 저장·digest·owner 검사 | 완료(개발 store) | local store만, `prod` 거부(D-15) |
| raw payload와 원장 metadata 분리 | 완료 | payload 금지 key, artifact 참조, 다른 Session artifact FK 거절 |
| 보관기간과 삭제 기초 계약 | 계약만 | retention 기록, `deletion_requests`·`deletion_tombstones`. purge·삭제 실행 없음 |
| 운영 로그 위생 | 확인 | 제출·오류·위조 cookie 흐름의 로그에 flag·token 없음 |
| 개인정보 삭제 역할·승인·감사 검토 | 검토 완료, **구현 미완** | [PRIVACY_ERASURE_REVIEW](PRIVACY_ERASURE_REVIEW.md) |

`GET /v1/sessions/{id}/evidence`를 구현하고 owner guard를 연결했다(T02 후속 의무 중 Evidence).

## 남은 것

- 삭제 실행 함수·전용 역할·승인 분리·삭제 통합 테스트(FR-10 게이트), purge job, orphan sweeper
- S3 호환 store(D-15), 런타임 역할 배포(D-14)
- Replay manifest·checkpoint(T12), SSE stream, 서명 checkpoint
