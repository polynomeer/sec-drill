## 후속 Task가 반드시 연결할 것

- 자원 id를 받는 모든 learner API는 처리 전 `OwnershipGuard.requireOwned`를 호출하고, cross-owner 404 테스트를 각 endpoint에 둔다. T04(Session·Report), T05(Submission), T09(Evidence·Artifact), T12(Report가 별도 id를 가지면 lookup 수정), SSE stream(T09·T12).
- 새 unsafe endpoint는 별도 작업 없이 Origin·CSRF 필터를 거친다. 예외 경로를 추가하려면 ADR이 필요하다.
- 운영자 endpoint는 `/ops/**` 아래에만 둔다. 발급·break-glass·2인 승인은 T14.

## 미검증

- 실제 OIDC provider(D-09 보류), 브라우저별 SameSite·Secure-on-localhost 동작
- 인증 경로 부하(매 요청 DB 조회), 다중 인스턴스
